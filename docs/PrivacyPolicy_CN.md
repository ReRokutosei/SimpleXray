# 隐私保护政策

版本：1.0  
生效日期：2026年8月10日

## 1. 隐私原则
本应用 SimpleXray 恪守**零远程数据收集**与**本地处理**的隐私原则。作为一个个人研究性质的代码项目，本应用不会向任何远程服务器搜集、追踪或外泄用户的个人隐私及设备信息。

## 2. 零数据收集与日志保留
本应用在架构层面未设计任何开发者远程统计、追踪或后台监测接口：
- **个人身份**：不收集姓名、账号、手机号、设备 ID、地理位置等任何个人标识。
- **配置与数据**：用户自行研究配置的数据文件均存储在 Android 设备的本地应用沙盒内，开发者无法也无意获取。
- **活动记录**：开发者不会对用户的任何点击、操作行为或运行记录进行追踪或记录。

## 3. 权限与存储隔离
本应用申请的系统权限仅用于满足 Android 本地框架功能调度。所有应用数据及偏好设置均被操作系统严格限定在本地私有沙盒目录中，受到系统进程隔离保护。

## 4. 开源审计与联系方式
本应用为全开源项目，源代码完全公开透明。任何个人均可随时对源代码进行安全与隐私审计。如有隐私方面的疑问，可通过 GitHub 项目页面的 Issue 提交技术交流。
